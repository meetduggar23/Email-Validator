# AI Email Validator

A full-stack email validation platform with real-time syntax, domain, MX, SMTP, and disposable email checks. Features bulk CSV processing, detailed analytics dashboard, exportable reports, and an interactive API playground. Built with React, TypeScript, Tailwind CSS, and Node.js.

## Getting Started

Run `npm install` in both `client/` and `server/` directories, then start the server with `npm run dev` in each. The client runs on port 5173 and the server on port 3000.
